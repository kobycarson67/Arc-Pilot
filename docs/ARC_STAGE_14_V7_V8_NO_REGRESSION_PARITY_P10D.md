## Stable ID rule

IDs use a readable lowercase ASCII prefix plus the first 12 lowercase hexadecimal characters of SHA-256 over `kind|course|approved source identity`.

- Standard identity uses Course plus exact external Standard code.
- Curriculum item identity uses Course, stable map identity, quarter ordinal, unit ordinal, exact timeframe, and exact focus.
- Lesson identity uses Course, source authority, and source Lesson code. Display title is excluded.
- Version identity combines stable parent identity with the SHA-256 of the exact source record.
- Competency identity preserves the accepted P7 competency code; the proposed version ID includes its exact source hash.

The generator and tests prove byte-for-byte reproducibility.
